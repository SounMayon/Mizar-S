# Mizar S - Modifications firmware

## Température
- Température maximale de sécurité : 285 °C.
- Température maximale sélectionnable : 270 °C.
- Marge HOTEND_OVERSHOOT conservée.

## LED
- Mode par défaut : blanc.
- Mode 0 : éteint.
- Mode 1 : couleur.
- Mode 2 : blanc.
- Mémorisation EEPROM conservée.

## Pause et reprise
- Restauration de la vitesse d'impression indépendante
  de la restauration de la position XY.
